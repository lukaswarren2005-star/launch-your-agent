# Weekly Radar — definition of done

1. `radar.md` names at least 3 real competitors for the project, each with at least one source link and what is working for them in the last 14 days as of this run (anything unverifiable is marked `unverified`).
2. `radar.md` lists at least 3 trends (formats, sounds, topics or aesthetics), each rated emerging / peaking / saturated / dead with a ride, bend or skip verdict and a link.
3. `plan.md` is a 7-day plan starting this Monday as of this run (date · channel · format · pillar · hook · brief link) that matches the project's content mix and weekly volume in memory.
4. Every brief in `briefs/` obeys the project's memory rules: voice, product colours/appearance, claims rules, wardrobe/setting rules, no logos where banned. No brief contains a fake testimonial or unsubstantiated claim.
5. `approvals.md` lists every proposed generation (number · model · what it makes · estimated credits · why) and **no Higgsfield generation tool was called** in this run.
6. Memory was updated: `projects/<slug>/watchlist.md` has this run's competitor snapshot and trend log, and any new rule landed in `learnings.md`.
